# ☕ Coffee House

A clean, multi-page coffee shop website built from scratch with HTML and CSS. Features a full storefront experience: landing page, menu, shop, order flow, and contact.

## Pages

| Page | Description |
|:--|:--|
| Home | Landing page with hero and highlights |
| Coffee | Menu with drink selections |
| Shop | Browse and explore products |
| Order | Place an order |
| About | The story behind the shop |
| Contact | Get in touch |

## Tech

```text
HTML  ·  CSS  ·  Responsive Layout
```
